## 7. Formation Grid Positions

### 3x3 Grid Layout

```
Position Names:
  [Left Shoulder]  [Head]       [Right Shoulder]   <- Rank 1 (100% attack)
  [Left Flank]     [Glasshouse] [Right Flank]      <- Rank 2 (90% attack)
  [Left Rear]      [Tail]       [Right Rear]       <- Rank 3 (75% attack)
```

### Vulnerability Ranking (most to least exposed)
1. **Shoulders** (both) - most vulnerable, exposed to frontal + flank
2. **Head** - second-highest exposure
3. **Flanks** - moderate
4. **Rear positions** - lower exposure
5. **Tail Gunner** - second-best protected
6. **Glasshouse** (center) - best protected position

### Formation Definitions

| Formation | Active Positions | Description |
|-----------|-----------------|-------------|
| **Phalanx** | All 9 | Full grid; maximum firepower |
| **Diamond** | 5: Center + 4 adjacent (Head, Flanks, Tail) | Protects Glasshouse from flank/rear |
| **Battle Line** | 6: Ranks 1 + 2 only | Maximizes 100%/90% attack rows |
| **Skirmish** | Sparse (varies) | Minimizes scatter damage |
| **Tee Forward** | T-shape: Rank 1 + center column | Balanced offense |
| **Enfilade** | Side-focused | Flanking fire concentration |
| **Tee Reverse** | Reversed T-shape | Rear-weighted |

Source: [Components of the Phalanx](https://galaxyonlineii.fandom.com/wiki/Components_of_the_Phalanx), [Fleet Design](https://galaxyonlineii.fandom.com/wiki/Fleet_Design)

### OSD (Overall Ship Defense) Formula

```
Damage Reduction = OSD * 0.03 / (OSD * 0.03 + 1)
```

## 17. Min/Max Hit Chance Clamp Values

**Not explicitly documented on the wiki.** Based on combat mechanics research:

- Hit chance is modified by Accuracy, Steering, Agility, and Dodge stats
- There is no documented minimum or maximum clamp in the wiki

- The system appears to allow hit chance to range from near-0% to near-100% based on stat differentials
