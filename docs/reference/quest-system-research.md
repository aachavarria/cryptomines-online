## 1. Quest System Overview

GO2 has two main quest categories:

1. **Development Quests** - One-time completion quests (main quests + side quests)
2. **Daily Quests** - Repeatable daily tasks for accumulated point rewards

The quest system serves as the primary tutorial and progression guide, especially in early game. Quest rewards sustain players for approximately one week before natural resource production must take over.

**Key mechanic**: Players are advised to claim main quest rewards immediately but SAVE side quest rewards until needed (they act as resource banks).

## 3. Development Quests - Side Quests

Side quests run in parallel with main quests. They are repeating/escalating quests where completing one tier unlocks the next harder tier. There are approximately 24 side quest categories:

### Resource Production Side Quests

| Category | Requirement Pattern | Example Levels |
|----------|-------------------|----------------|
| **Harvest Time** | Increase Metal productivity to X | Lv1: 2,180 ... Lv9+: 12,970+ |
| **Gathering He3** | Increase He3 productivity to X | Up to Lv20: 131,120 He3/hr |
| **Raising Morale** | Increase Gold productivity to X | Lv1: 500 reward ... Lv9: 40,000 reward |
| **Plentiful Resources** | Store X amount of Metal, He3, Gold | Escalating thresholds |

### Military Side Quests

| Category | Requirement Pattern |
|----------|-------------------|
| **Building Ships** | Own a set number of ships |
| **Ship Research** | Upgrade ship blueprints N times (each upgrade level counts) |
| **Parts Research** | Upgrade module parts N times |
| **Recruitment** | Recruit N commanders |
| **Beefing Up Defenses** | Build N defensive structures |
| **Military Ranks** | Own a commander card with star level X |

### Social/Economic Side Quests

| Category | Requirement Pattern |
|----------|-------------------|
| **Friendly Faces** | Add N friends |
| **Free Trade** | Reach trading volume X in auction house |
| **Contribution** | Reach N contribution points with corps (1 MP = 10,000 resources = 1 point) |
| **Staying Green** | Recycle N ships |
| **Joining Forces** | Join/participate in corps activities |

### Speedup Side Quests

| Category | Requirement | Reward Example |
|----------|------------|---------------|
| **Speed up Tech Advancement** | Use speedups on tech research | 2,000M, 3,000H, 2,200G + 5 Vouchers |
| **Speed up Module Blueprint Research** | Use speedups on module research | 2,600M, 4,200H, 3,000G + 5 Vouchers |
| **Speed up Shipbuilding** | Use speedups on ship construction (costs 8 MP) | 2,200M, 3,500H, 2,500G + 5 Vouchers |
| **Speed up Construction** | Use speedups on buildings | 2,500M, 4,000H, 2,800G + 5 Vouchers |

### Instance/Combat Side Quests

| Category | Requirement Pattern |
|----------|-------------------|
| **Instances** | Complete N instances |
| **Peace Agreement** | Use N truce cards |

### Side Quest Reward Scaling

Side quest rewards scale significantly as tiers increase:
- **Ship Blueprint Research**: Tier 1 (upgrade 1 BP) = ~5,000 resources; Tier max (upgrade 90 BPs) = ~3,000,000 resources
- **Contribution**: Tiers at 100, 500, 1,000, 2,000, 3,000, 5,000, 10,000, 20,000 points
- Special items appear at higher tiers: Galaxy Transfer, Construction Card, Sealing Card, Advanced Galaxy Transfer

## 4. Daily Quests

Daily quests reset at 1:00 PM server time. Completing them earns points toward accumulated rewards.

### Daily Quest List

| Quest | Requirement | Points |
|-------|------------|--------|
| **Daily Log In** | Log in to the game | 10 |
| **Collect Your Dues** | Harvest your own asteroids once | 4 |
| **Finders Keepers** | Harvest matured asteroids of 5 friends | 2 per friend (max 10) |
| **Helping Hand** | Speed up construction/upgrade for 5 friends | 2 per building (max 10) |
| **Need for Speed** | Speed up your own construction/upgrade | 3 |
| **Stockpiling** | Harvest from Resource Warehouse 3 times | 1 per harvest (max 3) |
| **Base Construction** | Give wrenches to 5 friends' bases | 2 per building (max 10) |
| **Voucher Rush** | Harvest matured vouchers from Celestial Industrial Base | 4 |
| **Donations** | Donate 200,000 resources to Corps | 6 |
| **Restricted Instances** | Attempt 2 Restricted Instances (win not required) | 5 per attempt (max 10) |

**Maximum daily points**: ~70 (if all quests completed fully)

### Accumulated Point Reward Tiers

| Points | Tier | Reward |
|--------|------|--------|
| 10 | Bronze | Random: Loudspeaker (50%), Resource Box (20%), SP Card (30%) |
| 30 | Silver | Random: Loudspeaker (40%), Resource Box (30%), SP Card (10%), Resource Packs (10%), He3/Metal Packs (10%) |
| 50 | Gold | Random: Resource Box (30%), SP Card (30%), Resource Packs (10%), Mining Boosts (5% ea), Cards/Items (2-5%) |
| 70 | Diamond | **Raw Gemstone (100%)** - guaranteed |

**Key mechanics:**
- Points reset daily but earned rewards persist
- Reaching a threshold doesn't consume points (reaching 70 gets ALL four tiers)
- The 70-point Diamond tier always gives a Raw Gemstone (valuable crafting material)
- Instance-related daily quests give bonus 5,000 Gold

## 6. Quest UI/UX Observations

Based on wiki screenshots and guide descriptions:

- **Quest Panel**: Accessible from main UI, shows current main quest and available side quests
- **Claim Rewards**: Players manually claim quest rewards (important: can delay claiming side quest rewards as resource banks)
- **Progress Tracking**: Each quest shows requirement and completion status
- **Notification**: Completed quests show visual indicator (likely exclamation mark or glow)
- **Daily Quest Panel**: Separate tab/section showing daily quest progress and point accumulation
- **Point Meter**: Visual display of accumulated daily points with tier thresholds marked

## 7. Design Implications for Cryptomines Online

### What our GDD already has (Section 2.10):
- First 9 main quests (partial) - missing quests 2, 4, 6, 8, and details on 12-28+
- Basic daily activity list (incomplete)
- Phase 2 tutorial chain extension (Section 8.12.1)

### What needs to be added to the GDD:
1. **Complete main quest chain** (all 28+ quests with exact rewards)
2. **Side quest system** (24 categories with escalating tiers)
3. **Daily quest system** (10 daily quests with point system and tier rewards)
4. **Quest reward items** (Loudspeaker, Truce Card, Construction Card, Revival Card, Galaxy Transfer, Healing Card, Mining Boosts, SP Cards, Resource Packs, Extra Tax, Raw Gemstone)
5. **Quest state machine** (sequential main quests, parallel side quests, daily reset cycle)
6. **Database schema** for quest tracking (player_quests, daily_quest_progress, side_quest_tiers)

### Simplifications for our clone:
- Remove social quests requiring friends (Finders Keepers, Helping Hand, Base Construction, Adding Friends, Friendly Faces) unless we implement friend system
- Remove chat-dependent quests (Loud and Clear, The Mail System) unless we implement chat
- Remove mall-point-dependent speedup quests unless we implement premium currency
- Consolidate the 24 side quest categories into fewer meaningful categories
- Normal instances can be simplified to fewer levels initially
- Scenario instances can be a Phase 3+ feature

### Recommended Phase 1 Quest Categories:
1. **Main Quest Chain**: Building progression quests (quests 1, 3, 5, 7, 9, 23, 25-27)
2. **Resource Side Quests**: Harvest Time, Gathering He3, Raising Morale, Plentiful Resources
3. **Daily Quests**: Daily Login, Collect Your Dues, Stockpiling (simplified set)

### Recommended Phase 2 Quest Categories:
1. **Main Quest Chain Extension**: Military quests (10-17, 24)
2. **Military Side Quests**: Building Ships, Ship Research, Parts Research, Recruitment, Beefing Up Defenses
3. **Instance Side Quests**: Complete N instances
4. **Daily Quests Extension**: Restricted Instances, Donations
